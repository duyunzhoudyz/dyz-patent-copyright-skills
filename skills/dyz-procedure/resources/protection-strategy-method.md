# 专利、商业秘密与公开策略方法

用于ANALYSIS-08：按资产作出有成本、证据、反证和责任人的保护选择。关联PROC-01/02、LIFE-02、RIGHTS-01/03/06及其AC、WP-05/08/10，不扩大真实法域支持。返回[程序入口](../SKILL.md)，完整输入及成稿见[北澄示范](protection-strategy-example.md)，CN来源见[规则研究](../../../references/jurisdictions/cn-strategy-evidence-20261101.md)。

## 1. 从原始经营和工程事实开始

先读技术材料、接触和公开历史，再读订单、成本、权属和行动计划，不要求用户先填“秘密成立”或保护分数。固定材料版本、来源、日期、权限及证明范围。

按可独立决策的技术信息切分资产，例如结构/动作、参数/更新规则、基线/新增配置；区分已公开、客户已知、未公开改进和第三方材料。新版本名不会改变旧内容的公开状态。

| 必须取得的事实 | 要回答的问题 |
| --- | --- |
| 工程原件与实施边界 | 技术是什么、哪些条件不可缺、能否与其他秘密独立实施、哪些效果有依据 |
| 订单与市场材料 | 已确认收入、预测数量、成本和替代需求是什么；是否有资产增量价值证据 |
| 接触与可观察性 | 产品购买、维修、客户端文件、调试输出、服务器访问各能恢复哪些信息 |
| 权利与措施 | 员工/承包商贡献、许可、保密合同、访问/备份/离职记录是否覆盖具体内容 |
| 日期与预算 | 何时公开、何时取得证据、何时拟展出及销售交付；报价项目、有效期、现金年度和双预算上限 |

缺件时继续整理已授权材料并完成可做的比较；仅阻塞依赖该缺件的结论。口述与原件冲突要实际更改判断，不把冲突藏进附录。

## 2. 逐资产比较四种选择

每行比较专利、秘密、防御公开和暂不新增权利，说明解决什么商业问题、放弃什么。

专利路线先核可保护技术范围、已有技术、充分公开和申请前事件。说明哪些必要细节将随申请公开、何时失去秘密优势，不能故意省略实施所需条件；普通营销摘要也不是合格说明书。随后问实际权项若获授权，能通过合法购样、授权测试或记录证明哪些要素，哪些内部步骤仍不可知。容易拍到结构只提高取证可行性，不证明有创造性或他人侵权。 员工任务、设备投入、实际贡献和合作关系须写成申请主体的事实依据，不能只列待签名字；将设计冻结、展台及允许维修拆解的销售交付分别排入控制计划。安排申请范围检索时，另列针对拟制造、销售产品的他人有效权项/状态及FTO核查责任，未知费用不能塞入原报价。

秘密路线围绕具体信息检查非公知、商业价值与事前相应措施。查访问人、载体、实际权限和记录，不能用NDA标题代替事实。上市可直接观察的结构、明文配置、足量精确输出可能削弱此路线；不同时间和接收范围分别分析。信息隐藏在服务器仍要检查运维、备份、离职和查询反推。预算包含持续管理，不把保存一个文档叫保护完成。 正文逐要件落实：非公知对应具体表格、历史或修正规则及客户可得粒度；商业价值对应探索成本或限定条件下的效果证据，分开未验证营销收益；事前措施对应人员、账户、具体载体及启用时点。逐项说明反推、备份、离职和日志缺口如何削弱判断，不能让规则三要件或案卷原文代替分析。

防御公开要明确准备公开什么技术、针对何种潜在申请以及为什么现有公开不足。正文应达到其特定技术目的所需粒度，并保留公众可及性、版本和日期证据。它不会产生排他权，不保证阻断所有申请，也不清除他人权利；已有公开的重新整理不能改写原日期。若内容已经充分公开且易定位，追加公开的边际价值可能低于存证或研发投入。

暂不申请或不发布也要写清：保留哪些措施、何时复查、哪些商业机会可能错过。对现有权利涉及缴费或放弃时，期限核对与有权决定另行进行，预算分析不触发自动弃权。

## 3. 把最强反证与取证路线写进结论

分别列资产价值、权利可执行性和竞争行为证据。销售增长不证明专利贡献，相似输出不证明同一表，自有申请不等于FTO。缺竞争样机、他人权项或当前状态不写零风险。

| 候选理由 | 至少要回应的反证 |
| --- | --- |
| 结构易观察，值得优先申请 | 常规部件组合、不同连接或分步动作能否绕开；拟范围是否仍有商业用途 |
| 内部参数难获得，倾向保密 | 独立研发、公开知识组合、客户重复查询、代维备份和离职载体是否削弱秘密 |
| 客户调试资料可识别侵权 | 文件/输出只证明其可恢复内容，不能直接证明内部训练、工艺或全部权项 |
| 公开可减少被他人申请的风险 | 所披露技术是否足够具体、日期是否可证、其他权利与未公开改进是否仍存在 |

每项写“当前能证什么—不能证什么—可合法补哪份证据—由谁做”。合法独立开发或公开产品反向工程与违反保密义务获得信息分开；不建议侵入、冒用账号或取得他人秘密。需要诉讼/行政措施时交对应专业人员，不预写法院或机关已作决定。

CN规则适用时间参考本次研究：2025修订反不正当竞争法自2025-10-15施行，商业秘密在第10条，民事举证安排在第39条；举证转换有启动条件。2020民事司法解释原文的旧编号不默改，2026-06-01施行的行政保护规章不替代民事规则。公开例外按专利法第24条及细则条件逐事件核，普通获准营销公开不能自动靠六个月补救。真实任务仍须核当时规则及专业解释。

## 4. 成本要能复算，价值不要伪精确

从给定报价列各年度支出和范围，再组合方案。每个方案明确共用项只计一次，保密设置费与持续管理、申请服务与程序准备金、公开制作与维护分开。表中给计算式、首年与观察窗总额、两类预算的余缺，并列至少一个成本变化情景；若超上限，说明删减哪项或转交预算决定，不能默默抬高预算。

报价不是现行官方费；准备金不代表必然花完，观察窗不等于完整权利期限。币种、税、有效期和阶段不一致时单列。过期报价为待更新，缺失鉴定、诉讼、第三方许可等费用为未报价，不当作零。实际支出、订单贡献和预期价值应分栏，不能从花钱多少推出权利价值。

市场数字用同一口径。先算单台售价减变动成本，再乘已确认数量；预测总数包含确认订单时不能重复加。固定成本、税务及资产归因不足就称给定口径贡献，不称净利润或专利估值。没有合理概率与因果证据时不用加权总分、虚构成功率或预期赔偿定价。

## 5. 先交实际正文，再附审计和行动

备忘录先写建议、预算和条件，再解释证据与反证。提供内部决定、申请范围/交底准备段、公开正文和客户摘要；不适用写原因。可以选择不发布，公开候选仍可供内部决策。 同时点名有权决定是否接受剩余商业风险的人及决策时点，列明易绕开、独立研发、秘密持续性与不新增公开等风险；区分业务负责人补证、专业人员审阅和商业风险接受，不把拟议决定写成已有批准。

内稿可写底线、秘密和报价；申请稿包含范围和必要支持；公开稿服务确定技术目的；客户摘要回答使用与服务。删密宣传摘要不冒充充分技术公开，含原案的完整示范不作外发包。

每个具体包注明实际已有正文版本、待生成文件、对象、用途、渠道、负责人、批准状态与恢复条件。已授权内部整理继续推进；待选代理、客户身份/账号、权属或支持未核时交明确补证责任，不编造确认。公开、申请、客户交付、签约及付款分别授权，不因已有申请号或NDA自动放行。

## 6. 后到材料改变的是哪些结论

保存旧版判断及其材料范围，逐内容对照新证据。公开日、文件形成日和本次取得日分开；已公开基线与后来新增内容分别核日期和权属，不让新内容借旧申请或旧秘密状态。新公开事实可能使“保密可持续”和“尚未自公开”的前提失效，但不能自动否定不在该文件内的结构或参数。

最终写受影响的正文、成本选择、检索范围、支持表与具体包，指定谁重审。更新事实后给新候选，不继承旧审阅；无影响的依据和历史失败保留。完成时报告实际产物、算术/静态检查和未执行的专业/外部环节，开发示范不计独立验收。
