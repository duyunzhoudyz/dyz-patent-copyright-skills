# CN实用新型结构起草与机械图证

用于已有获准部件、连接和名义几何的CN实用新型申请前工作稿。关联DRAFT-06、FIG-02、REVIEW-03，承接AC-DRAFT-06／AC-FIG-02／AC-REVIEW-03、WP-05/10。返回[专利入口](../SKILL.md)；规则判断读取[本次CN依据](../../../references/jurisdictions/cn-utility-evidence-20261101.md)，完整实例见[结构示范](utility-structure-example.md)及[可编辑图](utility-structure-views.svg)。没有结构事实时保留问题，不把方法改个名字充作装置。

## 1. 固定事实版本与类别

先确认任务为交底、完整起草、图证或核稿，以及申请前设计还是申请后修改。记录基座、活动件、连接件、环境对象各自来源；部件的实体性、相对位置、约束及运动不能靠名称推定。坐标、尺寸、连接和效果分别标为测量、设计、口述或未知。现有CAD也不当然证明设计与实物一致；没有CAD仍可在几何资料充分时制作明确标识的矢量设计草稿。

类别按实质手段判断。CN实用新型的形状／构造入口与新颖性、创造性、支持要求分别检查；不能因是实体产品即认定可授权。纯计算步骤不产生实体连接事实，不能增造常见传感器、处理器或执行器补齐。已知焊接等名称用于限定连接，与把新工艺步骤写进产品权项也应区分。规则版本、适用时点或领域边界未核时，将受影响结论留待专业核验。

冲突表必须同时列原文位置、冲突量、影响和确认来源。两个孔位差2mm是装配问题，不能以“看起来同轴”覆盖。允许先继续无争议的部件整理；使装配成立的数值不得任选。后到技术确认形成新输入版本，原记录原样保留；申请前可据确认形成候选，申请后还须对照真正原申请的组合与范围，不能把后补解释当作原始公开。

## 2. 建立能还原结构的最小模型

用一套坐标、单位与状态参数描述同一设计，优先解析几何、部件表与连接关系，不先凭美观绘图。每个实体列边界，孔和槽列从哪个实体扣除，环境工件与夹具零件分开。说明一体、固定、转动、滑动、接触或可拆连接；对间隙和干涉给计算，未给公差不写“可靠配合”。

对于滑移夹具，可按以下顺序核查，不需要新建生产几何引擎：

1. 固定基座原点和观察方向；长度单位统一，别把图纸像素当毫米。
2. 用一个位移参数生成各状态，固定件和工件保持原坐标；只移动源材料允许移动的零件。
3. 检查限制运动的接触面：闭合止挡在哪两面、压持面相对工件在哪里、销杆经过哪些孔、导向板为何不能直接抬出。
4. 分开必要运动与展示位置。人工退20mm的打开状态不等于有20mm行程止挡；插销可拔出不等于有防丢机构。
5. 核名义间隙、孔轴、覆盖、退让、插入深度；记录哪些仅是算术，哪些需要加工、公差、摩擦或受力验证。

示范中三实体共用q参数；闭合止挡和孔轴配合构成同一动作链。没有预紧结构时只能说明压持限制，不能推导出夹紧力。删除后挡、抗拔保险等未提供部件会缩小能够声称的作用；不能在图里悄悄补上。

## 3. 比较范围后再写权项

先逐关系比较最接近结构，区分共有手段、区别关系与待检索问题。合成D1没有真实公开日期或公开号，只能做给定技术比较；不能凭单份材料下全球新颖、创造性或FTO结论。

比较材料实际支持且有意义的范围；例如只写功能／一般滑移压持的宽稿、加入关键配合的结构组合、加入具体尺寸的窄稿，但不要求凑齐三个方案。只有一个受支持范围时，交该范围并说明其他概括为何缺依据；逐一解释实际候选的覆盖、原文支持、被对比结构覆盖的部分、容易绕开的方式及限缩代价。尺寸能追溯不表示必须进独立项；任意数值通常也不能替代区别手段的作用论证。

独立项应使读者能还原运动约束与配合关系。以本资源的夹具示范为例，只有其原始材料明确提供导向板在内伸顶缘下、中肋在顶缘间、压持舌从止挡间伸出、抵接时两孔同轴及销杆跨接滑块与基座时，才采用这些关系；示范结构不得转移到其他夹具。“定位模块”“锁定模块”不能取代有来源的关系。环境工件作为用途或配合对象应明确，不把它默认为夹具第四个零件。

结构条件也按方向核对：“只有抵靠时才同轴”只说明同轴需要抵靠，不能直接写成“抵靠状态下即同轴”；除非其他原句独立给出充分方向。实施方式若出现“此时必然同轴”，须同样删除或改回已支持的必要关系，不能紧接一句“此处待验证”后仍保留确定断言。未给出的解除方式、行程终点或额外稳定状态不凭装配常识加入实施方式；“取出插销即可离开”需要可拆卸性与其他约束的依据，不能由插销可插入自动推出。摘要沿用相同方向，不能因压缩句子升级关系。

从属项只加有来源的结构限定，引用路径中须已有其术语。对一体构造、销头止落及特定尺寸分别解释后备作用；不要用兄弟项补前置基础。每项的部件、关系、数值和组合均映射到原始材料，而非只搜相同词语。未提供的横销、弹簧、替代截面可以作绕开分析或研发问题，不能写成已支持实施例。

最强反证应进入取舍：如果已知滑块只把顶丝换成销，又在端部加常规止挡，为什么不是常规机械设计？明确接触定位与销孔对应的实际作用，同时承认没有比较检索或意外效果证据时论证仍弱。不得将“协同”“更可靠”等词代替反证回应。

## 4. 交连续正文和可核图

完整起草应给权项、技术领域、背景、实用新型内容、附图说明、具体实施方式和摘要全文。背景不能把合成D1写成真实已知专利；正文清楚标明演练身份，技术叙述仍应连续可读。实施方式解释装配路径、闭合／打开状态、解除过程及失败边界，不只是复制权项。

同一名义坐标生成三正投影，必要剖面展示被遮挡关系；孔是负几何，不画成额外杆件。每幅图记录观察方向、状态、剖切位置和来源。显示同一部件使用同一标记；隐线、中心线与剖面线分开。标记引线不能当作连接件；零件一体的表面不得凭分块建模画出不存在的装配缝。

申请图式候选与内部尺寸检查实际分组，不能仅加一句“请自行删除尺寸”。候选层保留清晰轮廓、必要图号和标记；内部层可加坐标、尺寸、冲突及核查说明。两层共享几何，导出其中一层要重新核页式、裁切和标记。规则并不在此被概括为“一切尺寸都禁止”；内部审图用途与正式申请材料的选择另审。

SVG源应保持可编辑并只含获准被动内容。可用绝对坐标和显式线段表达剖面线，无需脚本、外链或不受当前渲染器支持的绘图特性。该表示能完成来源明确的图稿，却不能冒充CAD、制图标准认证、实物测量或制造图。复杂曲面、未提供的零件内部或不能判断遮挡时，交具体缺图和领域复核任务，不猜结构。

## 5. 实际检查、变更及具体交接

先做与产物直接有关的确定性检查：摘要含标点字数、权项引用、图号和标记、尺寸运算、各投影共用坐标、SVG安全结构；保存实际输入与输出哈希。投影包围范围相同不等于所有边线可见性正确，局部名义配合通过也不代表完整干涉／受力检查。准确陈述检查范围，保留原始失败而非只报告修后零差。

由渲染责任人取得同版PNG并检查显示、缩放、长图裁切和图注；没有截图就写未执行。机械专业人员核几何表达、公差与制造意义，CN专业人员核权项范围、支持和申请图式，二者不能互相替代。作者自查、交叉模型审阅和正式专业签核分别记账。

孔位、连接或状态改变时，列明权项、实施例、摘要、图、支持记录与具体包的受影响范围；无影响也写依据。新候选绑定新字节，旧签核保留在旧版，不能自动迁移。原始输入、首答、首评、修订和后续复核分别保存。

交接按动作具体化：内部技术包可含原记录／矛盾和尺寸层；外部法律审阅包分清洁候选与支持附件；正式申请包需审定页式、图格式、真实主体和签署。逐包写文件／版本、接收对象、用途、渠道、有权批准人、授权状态和恢复条件。已授权的内部工作继续，真实外发、制造外包、发布、提交及付款分别确认，不能从起草许可推导。合成角色不产生现实签字；必要专业人员未到位只交待审工作稿。
