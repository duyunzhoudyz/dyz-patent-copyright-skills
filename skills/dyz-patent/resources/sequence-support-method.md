# 序列方向、数据图证与范围支持

用于DNA/RNA或短肽材料的序列身份、位点、数据归属和申请支持核对；对应FIG-03、ANALYSIS-05、DRAFT-08、REVIEW-02，接WP-05/10。先读[领域入口](topics.md)，规则判断按[来源研究](../../../references/jurisdictions/sequence-support-evidence-20261101.md)核适用日期。本文支持内部草稿方法，不代表生物功能、序列表合规或专业图式验收。

## 固定能复算的材料

不要只接收“第6位变异”“90%同源”或一张图片。取得并保全完整原串字节、来源位置/版本、分子类型、链方向、起始编号、连接/修饰、长度、样本ID和正式序列ID的对应。研究附件、申请原件、后来找回的数据、口述摘要分别标记；材料未给的原件内容不可由数据库相似结果替换。真实受限材料须先走宿主/工具路径与用途权限核对。

把三种身份分开：样本/批次名称；原始视图及其链；申请文件中的SEQ ID NO。样本标签纠错通常不意味着改写原序列或重新编号。来源缺页先冻结受影响身份判断，仍可完成其它可信样本的计算。

逐位展开当前完整序列。对长度L、从反向互补链第j位映射到规范链的第i位，用`i=L+1-j`，同时核互补碱基。反转、互补和反向互补是三种操作；只翻转坐标而保留碱基，会把替换含义弄错。给一个实际位置及完整转换后序列作交叉核对。RNA、修饰/简并符号、环状起点、缺口等须按材料及相应规则另处理，不能默认套普通DNA的ACGT转换。

## 数据身份先于图表

原始计数/单位/条件/重复层级、实验或合成来源、每次分母、缺失值和门槛须一并取得。先核每行总数再换算比例；“每次达到”不能被平均达到替代。样本标错时保留原计数，只修改证据允许修改的归属；未知不记0，不抹除不相关样本。没有逐条输入或执行实现时，重算汇总不等于复现原工具。

画图前列点表：图点ID→原记录/行→身份版本→数值/单位→条件→状态。给定九个点就画九个点，不编拟合、误差棒、统计显著性或生物活性。可以计算均值但标为派生值，不让它替换逐次数据。对后来更正，联动权项论据、说明、图注、图中标签和风险表，保留首版。

## 用反例检验范围

先定义比较关系：等长逐位比较还是有缺口比对，方向如何统一，是否允许长度变化，哪些位置/取代已公开。无这些定义，不给“90%相同”的虚假精度。对固定长度且仅替换的字母串，可计算`相同数/L`及离散错配上限；若每位有3个替代，恰有k处替换的序列数为`C(L,k)*3^k`。这是字符串计数，不是生物功能模型，也不能自动推广至插入删除。

逐项区分结构公开、功能证据、组合证据和整个范围的可实施性。单点数据显示某条件下表现，不能推出双点组合；图上序列接近不能推出活性或必要性。若某结构落入拟概括的结构集合但不满足拟声称效果，它反驳的是从该结构条件普遍推得效果的主张；不要进一步误说该对象满足含功能限定的完整权项。对没有测过的序列写未知，不能由一个反例宣布全属都无效。

对支持不足给出具体窄稿：选择原始文件已明确的结构、条件或技术关系，完整重写权项及说明核心段落，不只加“待核”一句。删除的功能保证、范围或组合要进差异表；后来数据改变判断不能倒填申请日原件。明确结构可在原稿找到，也不等于实际取得方式、真实用途或充分公开已完成。

## 序列表形式单独分诊

按实际申请日、路线及目标局核格式，而不是依据优先权日或工具“最新版”。本研究核到ST.26 v1.7及已公布、2027-07-01才生效的v2.0；跨日期再次核查，不把未来版本当当前要求。来源研究给出阈值、符号和方向入口，但不是全部条款或各局过渡规定清单。

对按序枚举、满足规定分子/连接条件的序列，分别计算总残基与“明确界定”残基。核酸通常的n、氨基酸通常的X与R等简并符号不可混算；先读该符号在原披露中的含义，再套相应阈值。短串仍可能有正文用途，但不任意分配正式序列编号。不能删去未知符号来凑合规，也不能以形式排除推断无专利意义。

内部大写比对图与ST.26正式表示不是同一产物。正式XML要另有申请信息、特征注释、版本及专用工具验证记录。未生成/未运行时如实标未执行；SVG解析、字符计数、WIPO Sequence形式校验均不证明生物作用、新颖性、广范围支持或合法修改。

## 可编辑图与交接

序列图保留完整对齐、方向箭头或明确方向文字、位号、稳定ID、差异位置和解释图例。数据图给轴/单位/条件、逐点来源和缺失状态；不让视觉简化破坏序列、位号或数值。SVG仅使用获准被动标签/属性，专业事实与实际浏览器显示分开复核。原生矢量可编辑，不代表符合某局正式附图规格。

交付四栏：候选权项/说明/图；内部原文支持与风险；待审专业人员及恢复条件；具体行动权限。拟交包列精确文件/版本与哈希、接收人、用途、渠道、批准人和状态；内部案卷及风险记录不默认随候选包外发。技术负责人确认方向、数据身份和图义；法域专业人员审充分公开、支持和修改；序列表人员审文件/工具；共享工作台核外发授权与固定包。条件未知只阻断相关动作，不能写成已获批准。
