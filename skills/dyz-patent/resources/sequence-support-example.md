## 2. B方向原件的实算

初始F04-R2只有S1标签和“位置6”摘要，缺链方向，不能据其确定规范位点。L01提供原始视图：`TACGGCTCCTAGGACTTGCAACGT`，左右分别5'与3'，该视图相对规范方向为反向互补链。先保留这串，再执行A与T、C与G互补并反转；规范结果为`ACGTTGCAAGTCCTAGGAGCCGTA`，逐位等于S2。

操作展开：原视图的逐字符互补串为`ATGCCGAGGATCCTGAACGTTGCA`，它在同一左右排列下是3'到5'；再反转得到规范5'到3'串`ACGTTGCAAGTCCTAGGAGCCGTA`。只反转原视图得到`TGCAACGTTCAGGATCCTCGGCAT`，不是规范S2；只互补同样不是规范S2。方向和碱基须同时处理。

24位位置关系为`i=25-j`。原视图第6位的参考A，在L01变体中为C；规范位置是`25-6=19`，参考A互补为T、变体C互补为G，所以是规范`19T>G`，不是规范`6G>A`。反向视图第19位C在本次仍是C，对应规范第6位G未改变。

由此仅把B的样本归属由摘要S1更正为S2/SEQ ID NO:3。F01/F02的S1原串及SEQ ID NO:2不改变；不将B改名覆盖原文件，不把错误标签从审计历史抹去。L01是在2026-10-31收到的后到记录，不成为2025-09-01原申请正文的一部分。S2结构早在F01-P2明列，B数据归属的当前解释来自L01，这两件事分开。

## 5. V1说明核心段落与图注

### 5.1 名称、领域与目的

名称：一种序列标识用DNA条码。该内部设计涉及以确定DNA序列作为标识的结构整理。待解决的问题是条码序列、编号与记录视图之间的一致对应，尤其是反向互补视图造成的位点和数据归属混淆。本稿未检索真实现有技术，不作“首次发现”或普遍优越性表述。

### 5.2 技术结构与编号

确定结构候选为S0和S2，分别对应SEQ ID NO:1和SEQ ID NO:3，完整5'到3'序列依次为ACGTTGCAAGTCCTAGGATCCGTA、ACGTTGCAAGTCCTAGGAGCCGTA。两者均含24个脱氧核苷酸，以普通相邻3'-5'磷酸二酯键连接，为无修饰、无插入删除的线性单链设计表示。S2相对S0仅在第19位由T变为G。

作为原始结构对照，S1对应SEQ ID NO:2，完整序列为ACGTTACAAGTCCTAGGATCCGTA，在第6位由G变为A；S3对应SEQ ID NO:4，完整序列为ACGTTACAAGTCCTAGGAGCCGTA，同时具有第6位和第19位替换。编号从首个5'端残基起连续1至24，不因数据标签纠正而改动。图1上部给出完整逐位对齐。

### 5.3 记录解释过程

收到一条已给定完整序列记录时，先保留原串及其方向，再对照规范5'到3'参考进行逐位核对。对明确为反向互补视图的24位记录，按互补映射A/T、C/G及反转顺序换算；位置映射采用`i=25-j`。本例B视图TACGGCTCCTAGGACTTGCAACGT经转换得到S2，视图第6位A改C对应规范第19位T改G。只看“第6位”的摘要或复制标签均不足以确定归属。此过程用于解释本例记录，没有新增生物处理或实体制备步骤。

### 5.4 有限数据说明

在题设C0下，A归S0，三次正确数分别98、97、99；B按L01更正归S2，三次96、94、95；C归S3，三次55、54、56，各次分母100。A/B达到题内每次90/100的阈值，C未达到；S1无性能数据。图1下部绘出这些九个原始点，不绘S1零点，不拟合曲线或添加经验误差棒。

这些值均是合成演练的给定虚拟计数，不是实测结果、湿实验或生物活性。原始逐条读入和可执行D0未给，当前工作只核算计数与方向归属。没有证据证明天然同源序列、全部单点/双点变体或任意互补实体具有同等表现。真实取得方式、实际用途与充分公开所需材料由技术负责人及CN专业审阅者另核。
