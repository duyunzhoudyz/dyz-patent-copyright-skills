# 三专业与复杂格式检查清单

按业务读取专利/软件/标准表；涉及Word、PDF、专业图或print时再读相应格式行。未取得文件或工具只记录未检查及恢复条件。 返回[技能入口](../SKILL.md)。

## 三专业审阅清单：静态、screen和print分开

以下是组织检查的方法，不是新增渲染能力或正式格式规则。根据当前任务选择适用行；每行记录对象/版本、实际检查范围、依据、发现和状态。只有实际执行且有对应证据才写该项通过；未执行、缺证、失败、不适用分开。不适用须说明对象为何没有此项，例如CLI无GUI，而非以没有浏览器为由把screen写不适用。

### 专利稿：图文对应与表达保留

| 检查面 | 静态检查动作 | 实际screen/print检查与返工归属 |
| --- | --- | --- |
| 图号/部件标号 | 建正文引用—图名—标号表；查缺号、重号、同物异号及未解释标号；不见图只报告清单差异 | screen逐图读可见标签；print另查页界及完整图。不能默选号码，语义对应交patent确认 |
| 连线/方向/流程 | 对照技术过程逐边列起终点、分支条件、成功/失败/回路；缺边先核原方案，不能自动造箭头 | screen查箭头可辨、连接端点、交叉遮挡与长标签；错逻辑回patent，正确逻辑显示错回生成层 |
| 正文—图—权项 | 对照术语、部件、步骤顺序、参数/单位、否定和例外；未画出的必要说明列问题 | screen看图注、公式/下标和符号是否可读；支持充分、范围及新增内容不由rendering批准 |
| 版本和图种 | 核当前稿各图/附件来源及版本，区分示意图、实际图、局部/多视图和未知视图 | 只有指定图种/视图被实际观察才记录覆盖；外观、化学、电路等专业正确性转相应专业，不由通用SVG检查替代 |
| 页与正式格式 | 对照页/图引用和可编辑源，不从HTML长度推物理页数 | print须实际输出及适用模板/纸张/字体规则；查截断、跨页图注、比例/线条/灰度等适用项；规则未知仅作内部检查 |

图文冲突的最小交接：源/图版本＋正文位置＋图/节点/边ID＋两个不同表达＋影响＋技术负责人待确认问题。专业修改确认后由生成/排版层再导出，不能把修复后的表现当作原方案已获支持。

**连线和细标签的复核动作。** 当图意依赖端点连接、结点或箭头方向时，不能只扫总览：先按已确认图意列出每条相关边的起点、终点、目标边界/引脚及交叉处是否有结点，再核源几何。SVG须考虑坐标变换、端帽、描边和符号边界；描边接近或重叠不证明中心线接到了指定端口，交叉无结点也不能擅自改为连接。标签逐个与图意/网表对照，特别核相似字形、数字和极性符号；没有权威图意时先列冲突待专业确认。

对容易被缩放掩盖的端点、交叉和标签，在当前实际渲染中查看局部放大，同时保留总图用于核布局及其它受影响位置。记录图版本、源字节、视口/缩放或裁剪范围，并把“源几何确认”和“实际图像所见”分别写明；局部图不能代替全图覆盖。修订后从新源重渲染，再核问题处和同类端点/标签。若只有原图截图，则可以交有依据的新SVG及复查坐标，但新图视觉状态仍为待核，不能搬用原截图关闭缺陷。

### 软件稿：真实操作、源行和秘密

| 检查面 | 静态检查动作 | 实际screen/print检查与返工归属 |
| --- | --- | --- |
| 产品/版本/操作 | 核范围、说明与表单的名称/版本及GUI/API/CLI/嵌入式形态；逐操作对输入、成功/失败、输出/退出码依据 | 真实操作记录须匹配版本/环境；只看说明HTML不等于运行软件。无GUI不造窗口截图，操作矛盾回software |
| 源码映射/连续性 | 按file_id、原行/列和选材区间核页界、重叠/缺口、长行折行；对排除清单，缺号可能是获准排除，不能补造 | screen看每个逻辑页界和长行；print核实际分页/字形。原行、选材行、折行、物理页各自统计，不以40行逻辑页代替官方规则 |
| 同版运行截图 | 核截图来源/版本/步骤与说明的对应；路径字符串不证明取得图片，设计图不冒充运行 | 实际观察有证据的界面范围、文字遮挡和错误状态；部分画面不证明完整流程，缺证回采集者 |
| 秘密与审计隔离 | 核正文、注释、示例输出、元数据及附件是否仍含待处理信息；只记位置和类别，不复制秘密原值 | 若格式支持批注/修订/隐藏层，另由获准工具检查实际输出；视觉无秘密不证明隐藏信息已净化。回software确定处理/用途，private_audit不混入正文 |
| 数量/一致性 | 对源清单、说明、表单的数量口径/日期/环境；缺字节不推总量 | screen/print仅验证呈现；权属、独创性、交存范围和官方接受由software专业判断 |

本技能不为核稿扩大源码授权范围，不执行被检查的软件，也不通过删秘密后的空白补重复代码。秘密尚待处理时，先保留内部定位单；不得标外发材料安全。

### 标准稿：强度、条件、量值与表格

| 检查面 | 静态检查动作 | 实际screen/print检查与返工归属 |
| --- | --- | --- |
| 规范语义 | 源/目标逐句对照应/宜/可、否定、适用条件、例外及规范性/资料性性质 | screen确认正文与附注未被隐藏、折叠或遗漏；任一语义变化回standards，不自行“润色” |
| 量值/单位/容差 | 按条款ID核数值、小数点、正负/不等号、单位、上/下标、范围与容差来源 | screen/print看符号缺字、字体替换、断行造成的误读；5变50是内容变化，即便作者称只改一字 |
| 表格/注/附录 | 对列标题、单位、数据所属行列、跨行关系、脚注标记/正文、附录性质和引用位置 | screen核长表宽度/横向覆盖；print查跨页表头、分行和注是否脱离对象，不把首屏代表全表 |
| 方法/验证对应 | 对条款版本、方法引用、试验范围和矩阵，查改条件后旧结果是否仍被引用 | 只检查内容保留与记录对应，不从呈现完整推出测量执行、符合性或认证 |
| 引用/意见/版本 | 查注日期版次、稳定条款ID、旧/新稿差异和未决标记 | screen/print核引用和待决项没有导出丢失；不自动升级引用，不把意见建议排成批准记录 |

缺全文只能核已有摘录或目录范围；缺实际测量不能补结果。标准性质/条款要求/法律合同纳入由standards分开判断，rendering不决定效力。

## 复杂图、办公文件与打印专题检查

这是一套按获准工具选择的审阅方法，不新增Word/PDF/CAD/化学或print适配器。先确认源文件/实际输出字节、用途、规则和工具权限；仅有提取文本时可以定位语义差异，但不能从提取结果断定原页面缺字或显示错误。引用他人观察须注明来源和覆盖，不冒称亲自打开。

| 分支 | 先做的内容比较 | 实际文件/环境到位后须检查 | 缺件时交付 |
| --- | --- | --- | --- |
| 机械/电路及多视图 | 部件/坐标方向/端口/连接、视图状态、尺度与正文对应 | 专用工具内视图/投影/剖面及导出一致性；专业正确性由领域人员核 | 逐冲突定位与待核图示任务，不猜缺面或连接 |
| 化学/生物/数据图 | 键型/立体标记/序列方向、上下标/单位、点值与来源 | 专业源格式与实际导出逐图对照；图义、序列表规则和数据真实性另审 | 现有文字/数据差异，未执行专业验证；不自动改化学式 |
| Word等可编辑稿 | 文本、表格、脚注、公式、图题/交叉引用、清洁/标记稿关系 | 获准副本查看修订/批注/域/隐藏文字/嵌入对象、页眉页脚、字体替换及分页；不自动接受修订或执行宏/外链 | 未取得字节/工具明确列未检，不能以可见正文断言隐藏层已清理 |
| PDF输出 | 与冻结源逐条核语义/表格对应，区分原生/扫描/OCR不确定 | 实际逐页渲染和必要文本层/批注/附件/表单/图层检查；遮黑是否仍可恢复原值由获准工具核验 | OCR/提取缺失只作线索，不凭一张图确认彻底脱敏 |
| 打印用途 | 目标规则/纸张/方向/边距/字体/比例与对象范围 | 当前实际输出逐页检查断字、图/表拆分、重复表头、页码/注释、上下标和线宽；如需实际设备质量则另收样张 | screen或PDF预览不代表物理打印/官方接受，缺哪个层就暂停哪个结论 |

步骤：先建立源—输出逐位置差异表，再区分源错误、生成错误和提取不确定；正确源不要为兼容导出而删专业限定。用获准副本修复拥有问题的层，输出每处原因/修正依据/责任人与同模板受影响范围；再重生成并绑定源、输出、工具/字体参数及实际观察。复杂图交专业人员审内容，原业务审语义，排版人员修表现；任何审阅都不替代整包专业签核或外发许可。

**合成例。** 源CO₂、2×10⁻⁴、±0.3、停机除外；提取候选CO2、2×104、0.3且无例外。报告分别列下标表示差异、指数符号丢失/数值语义风险、正负容差丢失和适用范围扩大。没有真实PDF时不能断言页面确实如此，先回生成/提取层核当前字节；不猜化学正确性或把源改成错误形式。旧首屏截图描述只作历史线索。交付静态问题单、四类文件/图检查计划与未检查清单，批注/隐藏附件未查不标包安全；缺图/文件/规则/实际观察就不造哈希或通过记录。
