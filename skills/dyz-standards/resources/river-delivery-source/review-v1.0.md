## 2 要求-方法-判定

<!-- ReviewConditions -->
对象为model.py指定哈希的一份Python 3.11串行内存模型，配置1.0；每个固定向量用其给定初始状态和完整原始字节。依预设顺序观察reason、全部结果状态及调用者状态是否被改动，逐项与预期比较。此模型无服务、真实终端或存储，不对性能、计量、不确定度或跨语言互操作作结论。

<!-- ReviewMatrix -->
| 条款 | 方法及输入类别 | 预期判定 |
| --- | --- | --- |
| RIV-01／R01 | 空、1024/1025字节、坏UTF-8、BOM、尾随值 | 对应size/encoding/json；拒绝不改状态 |
| RIV-02／R02 | 各层重复/转义同名、小数、指数、非有限数、-0、成员换序 | 指定禁止项为json；-0按0、对象换序不改语义 |
| RIV-03／R03 | 顶层数组、缺项/额外项、版本错 | shape先于version；不自动回退 |
| RIV-04／R04 | 大小写、Unicode、1/16/17字符 | 依ASCII和长度判batch |
| RIV-05／R05 | 0/1/4/5条、元素结构/未知字段 | records或field；不得删坏行 |
| RIV-06／R06 | 连续/跳号/降序/重复、布尔、null、0/1000/越界 | 只准连续1至n；null拒绝、0接收 |
| RIV-07／R08/10 | 最后一行非法、已接受批次、拒绝后更正 | 全批拒绝、状态不变或仅一次增加原值 |
| RIV-08／R09 | 字段错且顺序错、非法字段且批次已存在 | field优先于order/replay |

<!-- ReviewActual -->
实际运行的完整原58向量均与预期一致；其中配置1.0为40项，配置1.1为18项，按版本分别观察，不把1.1项计作1.0覆盖。结果、输入SHA-256和真实环境另在同目录model-run.json；原始stdout另保留并有哈希。原58项并非独立保留集；新增16项来源边界另属上一轮开发回归，不重复累计为新的专业通过数。
